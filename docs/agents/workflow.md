# Workflow

Read the tracker instructions and relevant glossary/ADRs first. Settled work needs no planning ceremony.

- Unclear large effort: `wayfinder`. Consequential choices: `grill-with-docs`.
- Evidence needed: `research` or `prototype`.
- Agreed feature: `to-spec`. Multi-session delivery: `to-tickets`.
- Ready ticket: `implement`. Ready ticket graph: `implement-spec`.
- Incoming issue: `triage`. Hard bug: `diagnosing-bugs`.
- Review Standards and Spec separately with `code-review`; `pr` prepares the PR body.
- Agents open PRs; humans review and merge. Use glossary terms; link ADRs.
